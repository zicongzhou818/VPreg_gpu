VPreg_gpu is a GPU-accelerated implementation of VPreg in MATLAB.
To run VPreg_gpu, please make sure your device has a GPU that is enabled in MATLAB.
The eventual runtime of a single registration varies depending on the size of the image and the enabled GPU.
